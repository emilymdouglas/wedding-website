# Wedding Website

Open this folder in VS Code and edit the HTML/CSS files.

## Files

- `index.html` — home page
- `details.html` — wedding schedule, venue, dress code, practical information
- `faq.html` — FAQ
- `styles.css` — all visual styling

## First things to customize

Search the project for:

- `[Partner]`
- `September 2027`
- `[RSVP DATE]`
- `you@example.com`
- `madison2027`

The password is defined near the bottom of each HTML file.

## Preview locally

In VS Code, you can simply open `index.html` in a browser. For a better development experience, install the VS Code "Live Server" extension and choose "Open with Live Server."

## Important password note

This is a lightweight front-end password gate. It is useful for keeping a casual wedding site private, but it is not a security system. Someone with technical access to the website files could discover the password.
